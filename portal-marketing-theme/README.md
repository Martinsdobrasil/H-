# Portal Marketing News Theme

Tema WordPress editorial pronto para portais de notícias com foco em publicidade, marketing e comunicação.

## Recursos principais

- Estrutura de homepage no estilo portal (manchete, destaques, editorias, mais lidas e newsletter).
- Compatibilidade com Elementor (incluindo registro de locations para Elementor Pro Theme Builder).
- Páginas de post com metadados, compartilhamento, relacionadas e comentários.
- Templates para categorias, arquivos, busca e páginas internas.
- Layout responsivo com prioridade mobile.
- Personalização de cor primária via Customizer.

## Instalação

1. Compacte a pasta `portal-marketing-theme` em `.zip`.
2. No WordPress: **Aparência > Temas > Adicionar novo > Enviar tema**.
3. Ative o tema.
4. Configure menus em **Aparência > Menus** e widgets em **Aparência > Widgets**.
5. (Opcional) Com Elementor Pro, construa Header/Footer/Templates no Theme Builder.

## Observações

- Para desempenho e SEO, use plugins especializados (cache, minificação, SEO e imagens WebP).
- O tema é original e inspirado em lógica editorial de portais de notícias.
